# ESP32-2432S028R 环境健康助手

独立的 PlatformIO/Arduino 固件，面向 ESP32-2432S028R（CYD）触摸屏开发板。

## 功能

- 触摸扫描并选择 2.4 GHz Wi-Fi，屏幕键盘输入密码；成功后凭据保存在 ESP32 NVS。
- 中文显示当前温度、湿度、露点 / 结露余量、环境等级和调整建议。
- 保存最近约 6 分钟数据，显示温湿度曲线、均值和范围；网页另提供过去 24 小时曲线（从 TF 卡记录按 5 分钟聚合）与超标统计。
- 网页显示绝对湿度、焓值和霉变风险计时；湿度持续偏高或结露余量过小时给出对应提醒。
- 以 1 秒间隔采样，识别吹气、快速开窗 / 降温、加湿和除湿等短时事件；事件会显示在网页并进入 Miku 对话上下文。
- 数值采用平滑过渡；指数滑动平均抑制 SHT3x 读数跳动，时间线性回归给出约 10 分钟趋势估计。
- 默认白色日间界面，右上角可切换低亮度夜间界面。
- 极端温湿度、干燥、潮湿、闷热等场景给出健康提示与决策辅助。
- ESP32 内置局域网网页；电脑使用顶部导航，手机使用底部导航，可在环境、趋势、智能助手和设备之间切换。温湿度趋势使用独立刻度。
- “宠物”页可选择 Miku、月兔、赤狐或围巾企鹅：点按挥手、长按跳跃、滑动时看向对应方向，并随环境舒适度自动切换状态。
- 系统采用 240×320 竖屏布局，开机默认进入宠物页；环境监测作为独立功能保留。
- 局域网网页可填写 DeepSeek API Key 并与 Miku 对话；密钥仅保存在 ESP32 NVS，不写入源码、不通过接口回显。对话会携带当前温湿度和环境等级作为上下文。
- TF 卡挂载后，每分钟将温湿度及运行时间追加到 `environment.csv`。
- 已接入 Qwen 实时语音合成和 I2S/DAC 音频输出，可朗读 DeepSeek 回复；另有喇叭测试页面。源码接入不代表实物播音效果已验收。

宠物动画先在离屏画布合成，再一次性推送到屏幕，避免逐层擦除产生闪烁。每款外观使用 57 帧 RGB565 RLE 动画，放在 TF 卡根目录的 `miku.rle`、`rabbit.rle`、`fox.rle`、`penguin.rle`，固件启动时会校验文件头、尺寸和帧索引；卡未插入或文件损坏时会安全降级，不会读取越界。`tools/make_miku_asset.py` 可从保留的原始头文件重新生成该文件。网页的 `/miku-upload` 页面可逐个安装或更新外观。固件先校验临时文件，再替换对应动画，安装后可直接选择。Miku 沿用设备已有 Codex Pet 资产，另外三款由 `tools/make_pet_skins.py` 生成。

## 温湿度接口

板载 4 针接口的 DATA 脚是 `GPIO27`，现已改用 SHT3x（I2C）温湿度传感器：

- SDA：`GPIO27`（沿用原接口的 DATA 脚）
- SCL：`GPIO22`（P3 排针）
- VCC：3.3V
- GND：GND

SHT3x 模块默认 I²C 地址为 `0x44`（ADDR 拉高为 `0x45`）。GY-SHT3x 模块自带 4.7 kΩ 上拉，裸芯片需在 SDA/SCL 外接 4.7～10 kΩ 上拉到 3.3V。注意 `GPIO26` 是喇叭 DAC 输出，不可占用。

## 构建与烧录

```powershell
cd cyd-environment
pio device list
pio run
pio run -t upload --upload-port COM7
pio device monitor -p COM7 -b 115200
```

从仓库根目录运行，串口号按 `pio device list` 的结果替换。当前只支持 2.4 GHz Wi-Fi。SHT3x 存在测量误差，预测是用于决策提示的短期线性趋势，不是专业气象预测或医疗结论。

## 手机或电脑查看

在屏幕“网络”页选择 Wi-Fi 并连接。成功后页面会显示 `http://192.168.x.x` 一类地址；让手机或电脑连接同一个 Wi-Fi，并在浏览器中打开该地址。ESP32 连接手机热点时，也可在开热点的手机上尝试打开，但部分系统的热点客户端隔离策略可能阻止访问。

在设备页展开「DeepSeek 密钥设置」保存 API Key，然后进入独立的「智能助手」页（`/assistant`）。每次请求携带现场数据和最近最多 4 轮完整问答，历史正文合计不超过 3,600 个 UTF-8 字节。页面在当前浏览器标签页保存最近 30 轮和草稿，刷新可以续聊。「新对话」会清空当前会话。ESP32 气泡容纳三行，按字宽换行，超出才显示省略号；上位机显示完整回复。

在助手页的「现场数据与宠物设置」可选择已安装外观、开启或关闭「朗读助手回复」。外观与开关随设备保存。区间提醒仍由原提醒页单独设置。需要语音时，在设备页打开「语音设置」（`/qwen-config`），保存百炼 API Key 和音色 ID，再发送对话。设备页也可播放本地测试音、查看播放状态及最近一次语音的缓冲中断 / 写入未完成计数；`/speaker-test` 保留独立测试入口，`/tts/status` 保留文字状态接口。

语音以 8 kHz PCM16 接收，I2S/DAC 以 16 kHz 输出（音频任务内 2x 线性插值），按原始振幅映射到内置 8 位 DAC。TTS 语音额外加 6 dB 数字增益，并用一阶误差反馈抑制 8-bit 量化毛刺；本地测试音不加增益、不做整形。结束时先淡出并排空 DMA，再关闭 DAC2 模拟输出、将 GPIO26 保持低电平。音频使用 DAC2/GPIO26，DAC1/GPIO25 保持关闭；触摸仍可使用，只在中断指示按下时采样。播放完成后的 DMA 排空期间，继续暂停宠物动画和室外天气请求。为减少播放中的断续和噼啪：网络短暂断粮时只补中点静音、不再反复关闭/重启 DAC；播放期间暂停 SD 卡写入，并临时降低 Wi-Fi 发射功率；每次重连后重新关闭 Wi-Fi 省电模式。串口播放结束日志里的 `peak` 是本次 TTS 解码后的原始峰值，用来判断增益是否过大（接近 32767 时 2x 会削波）。

串口调试（115200 波特）：`tone` 播放 1.5 秒本地测试音（默认 60% 振幅，满幅容易让小功放削波），`tone 20` 可指定 1～100% 的测试振幅；`quiettone` 临时关闭无线和背光播放纯音，结束后自动恢复，用于排查板上干扰；`say 文本` 测试 Qwen 朗读；`status` 输出与 `/api` 相同的环境及音频状态 JSON；`heap` 查看可用内存。计数为零表示未检测到缓冲断流或写入不足，不能据此判断实物底噪已消失。
